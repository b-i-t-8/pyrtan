pyrtan catalog

Ready-made trees you can download and run. Each one is a single tested TOML file, under its author's licence. pyrtan pull NAMESPACE/NAME checks the file against index.json before saving it. Where hubs have hit a case a tree doesn't cover, its gap reports are shown beside it.
